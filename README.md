# .NET Engineering Lab

A hands-on engineering workspace focused on building reliable, maintainable and scalable backend applications using C# and ASP.NET Core.

This repository documents my practical learning and engineering experiments across backend development, API design, software architecture, testing, databases, distributed systems and cloud engineering.

## 🎯 Objectives

- Strengthen C# and modern .NET development skills.
- Build RESTful APIs using ASP.NET Core.
- Understand dependency injection, middleware and application architecture.
- Work with relational databases and Entity Framework Core.
- Implement automated testing and improve code quality.
- Explore distributed systems, messaging and asynchronous processing.
- Learn cloud deployment, infrastructure and CI/CD using AWS.

## 🚀 Getting Started

### Prerequisites

- .NET 10 SDK
- Git
- Visual Studio 2022 or Visual Studio Code

### Clone the repository

```bash
git clone https://github.com/Dhanasooryaa18/dotnet-engineering-lab.git
cd dotnet-engineering-lab
```

### Run the API

```bash
dotnet run --project EngineeringLab.Api
```

The application will display its local listening address in the terminal.

Use the generated `/weatherforecast` endpoint to verify the initial API template is responding.
